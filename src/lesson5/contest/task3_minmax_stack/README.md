# Задача C. Обобщённый стек с минимумом

Реализуйте стек, который за `O(1)` умеет сообщать минимальный и максимальный из лежащих в нём элементов. Стек должен работать с элементами двух типов: целыми числами и строками. Числа сравниваются по значению, строки — лексикографически (как `String.compareTo`).

| Команда | Действие | Вывод |
|---------|----------|-------|
| `PUSH x` | положить `x` на вершину | нет |
| `POP` | снять элемент с вершины | снятый элемент |
| `TOP` | посмотреть элемент на вершине | элемент |
| `MIN` | минимальный элемент стека | элемент |
| `MAX` | максимальный элемент стека | элемент |
| `SIZE` | количество элементов | число |

Если стек пуст, команды `POP`, `TOP`, `MIN` и `MAX` печатают `EMPTY` и ничего не меняют.

## Ввод

В первой строке тип элементов (`INT` или `STRING`) и целое число `q`, количество команд.

В следующих `q` строках по одной команде.

## Вывод

Для каждой команды, кроме `PUSH`, одна строка с ответом.

## Ограничения

- `1 ≤ q ≤ 200 000`
- для `INT`: `|x| ≤ 10^18`
- для `STRING`: `x` — от `1` до `20` строчных латинских букв

## Примеры

Ввод:

```
INT 10
PUSH 5
PUSH 10
PUSH -3
MIN
MAX
POP
MIN
SIZE
POP
POP
```

Вывод:

```
-3
10
-3
5
2
10
5
```

Ввод:

```
STRING 9
MIN
PUSH pear
PUSH apple
PUSH zebra
MIN
MAX
POP
POP
TOP
```

Вывод:

```
EMPTY
apple
zebra
zebra
apple
pear
```

## Подсказка

Напишите один обобщённый класс `MinMaxStack<T extends Comparable<? super T>>` и создайте из него `MinMaxStack<Long>` или `MinMaxStack<String>` в зависимости от первой строки. Вместе с каждым элементом храните минимум и максимум стека на момент его добавления. Числа как строки сравнивать нельзя: `"10" < "9"`.
