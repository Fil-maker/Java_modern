# Задача A. Безопасный калькулятор

Калькулятор получает выражения вида `a op b`, где `a` и `b` — целые числа, а `op` — операция. Часть выражений записана с ошибками. Калькулятор не должен падать ни на одном выражении: для каждого он печатает либо результат, либо сообщение об ошибке.

Выражение разбивается на части по пробелам. Корректное выражение состоит ровно из трёх частей.

Числом считается запись из необязательного знака `+` или `-` и одной или нескольких цифр (ведущие нули допускаются), значение которой лежит в диапазоне типа `long`: от `-9223372036854775808` до `9223372036854775807`.

| Операция | Результат |
|----------|-----------|
| `+` | сумма |
| `-` | разность |
| `*` | произведение |
| `/` | целая часть от деления, округлённая к нулю: `-7 / 2 = -3` |
| `%` | остаток со знаком делимого: `-7 % 2 = -1`, `7 % -2 = 1` |

Ошибки проверяются строго в таком порядке, печатается первая найденная:

| Сообщение | Когда |
|-----------|-------|
| `ERROR FORMAT` | частей не три |
| `ERROR NUMBER` | первая или третья часть — не число |
| `ERROR OPERATION` | вторая часть — не одна из `+ - * / %` |
| `ERROR DIVISION` | деление `/` или `%` на ноль |
| `ERROR OVERFLOW` | точный результат не помещается в `long` |

## Ввод

В первой строке целое число `q`, количество выражений.

В следующих `q` строках по одному выражению. Строка не пустая, не начинается и не заканчивается пробелом, части разделены ровно одним пробелом. Строка состоит из печатных символов ASCII.

## Вывод

Для каждого выражения одна строка: результат или сообщение об ошибке.

## Ограничения

- `1 ≤ q ≤ 100 000`
- длина каждой строки не больше `60` символов

## Пример

Ввод:

```
9
12 + 30
7 / 0
-7 / 2
abc * 2
10 %
2 ^ 10
9223372036854775807 + 1
-0008 * +5
1 + 2 + 3
```

Вывод:

```
42
ERROR DIVISION
-3
ERROR NUMBER
ERROR FORMAT
ERROR OPERATION
ERROR OVERFLOW
-40
ERROR FORMAT
```

## Подсказка

Заведите своё исключение с кодом ошибки и бросайте его из метода разбора выражения. `Long.parseLong` бросает `NumberFormatException`. Методы `Math.addExact`, `Math.subtractExact` и `Math.multiplyExact` бросают `ArithmeticException` при переполнении. Помните про единственный случай переполнения при делении: `-9223372036854775808 / -1`.
