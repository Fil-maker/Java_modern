# Задача B. Банк

Смоделируйте работу банка. Счёт определяется именем, баланс — целое число, изначально счетов нет. Обработайте последовательность команд.

| Команда | Действие | Вывод при успехе |
|---------|----------|------------------|
| `OPEN id x` | открыть счёт `id` с начальным балансом `x` | `OK` |
| `DEPOSIT id x` | положить `x` на счёт `id` | `OK` |
| `WITHDRAW id x` | снять `x` со счёта `id` | `OK` |
| `TRANSFER a b x` | перевести `x` со счёта `a` на счёт `b` | `OK` |
| `BALANCE id` | узнать баланс счёта `id` | баланс |

Если команду выполнить нельзя, она не меняет ни одного баланса и печатает сообщение об ошибке. Ошибки проверяются строго в таком порядке, печатается первая найденная:

| Сообщение | Когда |
|-----------|-------|
| `ERROR AMOUNT` | сумма `x` не положительна; для `OPEN` — отрицательна (открыть счёт с нулём можно) |
| `ERROR NO_ACCOUNT` | счёта с таким именем нет (для `TRANSFER` — нет хотя бы одного из двух) |
| `ERROR EXISTS` | `OPEN` для уже открытого счёта |
| `ERROR FUNDS k` | на счёте списания меньше `x`; `k` — сколько не хватает |

Перевод на тот же счёт (`a = b`) разрешён: он проверяется как обычный перевод и баланс не меняет.

## Ввод

В первой строке целое число `q`, количество команд.

В следующих `q` строках по одной команде в формате из таблицы. Части разделены одним пробелом.

## Вывод

Для каждой команды одна строка: результат или сообщение об ошибке.

## Ограничения

- `1 ≤ q ≤ 100 000`
- имя счёта — от `1` до `10` строчных латинских букв
- `|x| ≤ 10^12`

## Пример

Ввод:

```
12
OPEN alice 1000
OPEN bob 250
TRANSFER alice bob 300
WITHDRAW bob 600
TRANSFER bob carol 10
DEPOSIT alice -5
DEPOSIT carol -5
OPEN bob 1
TRANSFER bob alice 550
BALANCE alice
BALANCE bob
OPEN carol 0
```

Вывод:

```
OK
OK
OK
ERROR FUNDS 50
ERROR NO_ACCOUNT
ERROR AMOUNT
ERROR AMOUNT
ERROR EXISTS
OK
1250
0
OK
```

## Подсказка

Нехватка денег — ожидаемая ситуация: сделайте для неё проверяемое исключение с полем «сколько не хватает». Перевод должен быть атомарным: сначала проверьте всё, что может пойти не так, и только потом меняйте балансы. Используйте `long`.
